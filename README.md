# GranaBank 🏦

App bancaria del Club Atlético Lanús. Permite visualizar movimientos, filtrarlos y buscarlos.

## Tecnologías

- **Frontend:** Next.js + TypeScript + Tailwind CSS
- **Backend:** Express + Node.js + TypeScript
- **Base de datos:** PostgreSQL

## Requisitos previos

- Node.js instalado
- PostgreSQL corriendo en puerto 5433
- Base de datos `granabank` creada

## Instalación

### Backend
```bash
cd back
npm install
npm run dev
```

### Frontend
```bash
cd front
npm install
npm run dev
```
